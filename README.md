# Vector-Exploration
Playing with vectors using Javascript. The delta of mouse movements are stored in an object. There is also a boundary of 30px around the button and when the boundary is crossed, the vector value is added to the position of the button in the correct direction. This was a goofy little project to explore how the math behind actions like this works. Feel free to steal this and use it in a gag website.

I was inspired to make this not only because I wanted to experiment with vectors but because I saw a Tik-Tok of a similar concept and every comment was making fun of them for using A.I. to make it so I wanted to see if I could do it but, without the A.I.
